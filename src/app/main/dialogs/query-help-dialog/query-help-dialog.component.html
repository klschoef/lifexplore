CLIP Query

Just enter any text to perform a CLIP query.

Database Query

Use any of the following parameters to (additionally) query the database and filter content:
  • {{textCommandPrefix.value}}y  year (e.g., 2019 or 2019,2020)
  • {{textCommandPrefix.value}}m  month (e.g., jan, jan-apr, 3,5,7)
  • {{textCommandPrefix.value}}d  day (e.g., 15, 20-23, 1,15,28)
  • {{textCommandPrefix.value}}wd  weekday (e.g., mon-fri or fri-mon)
  • {{textCommandPrefix.value}}t  time of day (morning, noon, afternoon, evening, night)
  • {{textCommandPrefix.value}}trip  trip label (e.g., bangkok or greece,vietnam)
  • {{textCommandPrefix.value}}before  before date (e.g., 2020-03-15 or 2020)
  • {{textCommandPrefix.value}}after  after date (e.g., 2019-05-01)
  • {{textCommandPrefix.value}}sort  sort by date (newest or oldest)
  • {{textCommandPrefix.value}}not  negative phrase (e.g., Guinness)

Result Limits

  • Use All Images to display all available images for a query.
  • Use Less Duplicates to filter out temporally consecutive images in the result set hat are very similar.
  • Use Distinctive to filter out temporally consecutive images in the result set that are similar.
  • Use First Image/Day to display only the first image of the day in the result set.

Thumbnail Actions

  • Click thumbnail (or press space) to open full-screen view.
  • Click Date to perform a full day (or hour or minute) query in a new tab.
  • Click Similar to perform a similarity query in a new tab.
  • Click Submit to send image to DRES.

Keyboard Shortcuts

  • left/right: switch result image
  • tab/shit+tab: switch page
  • 1-9: goto page
  • e: extend query (locks other shortcuts)
  • CRTL + e defocus search field (unlocks other shortcuts)
  • q: edit query (locks other shortcuts)
  • x: reset query
  • i: show/hide Info Dialog
  • h: show/hide History
  • t: show/hide Tuning Dialog
  • m: switch query mode
  • r: switch result mode
  • Space/Esc: close full-screen view of image
  • s: submit results in full-screen view of image
